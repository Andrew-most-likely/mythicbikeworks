Content rules

Hosting and domain

  1. Connect the GitHub repo to Cloudflare Pages; every push publishes.
  2. If the domain has email, copy its mail records to Cloudflare first.
  3. In Wix, unlock the domain and get the transfer code; transfer to Cloudflare Registrar (no transfer within 60 days of registering or a previous transfer).
  4. Add mythicbikeworks.com as the Pages custom domain; HTTPS is automatic.
  5. Cloudflare Email Routing for shop@mythicbikeworks.com; Web Analytics for visitor stats.
